## Валідація

### Порожня назва
- [ ] Спроба зберегти порожню назву показує помилку "Назва не може бути порожньою"
- [ ] Помилка відображається червоним текстом під input полем
- [ ] Поле редагування залишається відкритим

### Заборонені символи
Протестувати символи: `/`, `\`, `*`, `?`, `"`, `<`, `>`, `|`, `@`, `#`, `$`, `%`

- [ ] Спроба використати `/` показує помилку про заборонені символи
- [ ] Спроба використати `\` показує помилку
- [ ] Спроба використати `*` показує помилку
- [ ] Повідомлення містить список дозволених символів

### Дозволені символи
Протестувати: літери (українські та латинські), цифри, пробіли, дефіси, підкреслення

- [ ] Українські букви (а-я, і, ї, є, ґ) працюють
- [ ] Латинські букви (a-z, A-Z) працюють
- [ ] Цифри (0-9) працюють
- [ ] Пробіли працюють
- [ ] Дефіси `-` працюють
- [ ] Підкреслення `_` працюють

### Дублікати документів
- [ ] Створити два документи в одній папці
- [ ] Спроба перейменувати один на ім'я іншого показує помилку "Документ з такою назвою вже існує"
- [ ] Документи з однаковими назвами в РІЗНИХ папках дозволені
- [ ] Документи з однаковими назвами в РІЗНИХ категоріях дозволені

### Дублікати папок
- [ ] Створити дві папки в одній категорії
- [ ] Спроба перейменувати одну на ім'я іншої показує помилку "Папка з такою назвою вже існує"
- [ ] Папки з однаковими назвами в РІЗНИХ категоріях дозволені

## Захист розширення файлу

### Зміна розширення
- [ ] Завантажити файл test.pdf
- [ ] Перейменувати на test.txt
- [ ] Розширення залишається .pdf (назва: test.pdf)
- [ ] Показується alert "Розширення файлу не можна змінити"

### Без розширення
- [ ] Завантажити файл test.pdf
- [ ] Перейменувати на "просто назва" (без крапки)
- [ ] Розширення автоматично додається: "просто назва.pdf"

### Правильна зміна
- [ ] Завантажити файл test.pdf
- [ ] Перейменувати на newname.pdf
- [ ] Зміна успішна, файл тепер називається newname.pdf

## Крайні випадки

### Режим вибору (Selection Mode)
- [ ] Активувати режим вибору (кнопка "Вибрати")
- [ ] Подвійний клік на документі НЕ активує редагування
- [ ] Кнопка "Перейменувати" прихована для документів
- [ ] Вимкнути режим вибору - перейменування знову працює

### Drag & Drop
- [ ] Почати перетягування документа
- [ ] Подвійний клік під час drag НЕ активує редагування
- [ ] Після drop - перейменування працює

### Одночасне редагування

- [ ] Подвійний клік на іншому документі
- [ ] Перше редагування скасовується, друге активується
- [ ] Тільки один елемент в режимі редагування одночасно

### Довгі назви
- [ ] Ввести дуже довгу назву (100+ символів)
- [ ] Назва зберігається
- [ ] В UI назва truncated з tooltip
- [ ] При повторному редагуванні показується повна назва
